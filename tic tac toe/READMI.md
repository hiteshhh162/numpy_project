# 🎮 Tic Tac Toe Game using Python & NumPy

A simple Tic Tac Toe game built using **Python** and **NumPy**.

This project allows two players (X and O) to play Tic Tac Toe in the terminal. The game automatically detects:

- ✅ Row wins
- ✅ Column wins
- ✅ Diagonal wins
- ✅ Draw matches
- ✅ Invalid moves

---

## 🚀 Features

- Built with Python
- Uses NumPy 2D arrays
- Winner detection logic
- Draw detection
- Input validation
- Clean and beginner-friendly code
